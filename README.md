# Daily Habit Tracker App

An interactive web application built using AI-assisted engineering tools. Users can register, track daily habits, view completion streaks, and manage routines with full real-time database storage.

## Deployed Application
- **Live Site:** https://habit-tracker-micen.netlify.app
- **Demo Video:** [Watch Demo Video on YouTube](https://youtu.be/UlIzrsmzuzk)

## Features
- **Data Persistence:** Cloud database storage via Supabase.
- **Full CRUD Functionality:**
  - **Create:** Add new habits with custom categories.
  - **Read:** Retrieve active habits and streak counts.
  - **Update:** Toggle completion status and update streaks dynamically.
  - **Delete:** Remove unwanted habits.

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Backend & Database:** Supabase
- **Deployment:** Netlify
